الرئيسية المهارات المشاريع تواصل معي

الأدوات والبرامج المستخدمة

Adobe Photoshop
تعديل الصور ورسم الواجهات وتصميم الجرافيك.
VS Code
محرر الأكواد الرئيسي لكتابة HTML, CSS, C++, Python.
GDevelop
تطوير الألعاب والتطبيقات التعليمية التفاعلية للأطفال.
Canva
تصميم الصور والقصص وواجهات المستخدم والفيديوهات.
CapCut
مونتاج الفيديوهات وتعديلها باستخدام أدوات الذكاء الاصطناعي.
Genially
إنشاء العروض التفاعلية والألعاب والأنشطة التعليمية الجذابة.
Kahoot
تصميم الألعاب التعليمية والاختبارات التفاعلية المسلية.
Zapworks
إنشاء وتطوير تجارب الواقع المعزز (AR) التفاعلية.
Flow
إنشاء وتوليد الفيديوهات باستخدام الذكاء الاصطناعي.
Gemini
المساعد الذكي لتوليد الأفكار وتطوير وكتابة الأكواد.
Freepik
الحصول على رسومات عالية الجودة وأصول بصرية للتصميم.
Book Creator
تصميم وإنشاء الكتب القصصية والقصص الرقمية التفاعلية للأطفال.
